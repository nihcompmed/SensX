## DeepSpot Setup

1. Clone official DeepSpot repository to `deepspot` folder.
2. Download Deepspot pretrained model weights to `DeepSpot_pretrained_model_weights` folder.
3. Make sure UNI is already setup in higher level folder of UNI.

---

## Custom wrapper

`qoi_wrapper_VALIDATE.py` is our custom wrapper for DeepSpot that takes arguments as spot and neighbors, and returns DeepSpot gene predictions.
